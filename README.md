# primeros-pasos-github
##Pasos para crear y conectar repositorios

1. Entras a Git Bash e introduces el comando `Git init` en la ruta deseada para crear el repositorio local
2. Introduces el comando `git add <fichero>` para añadir el fichero al repositorio local
3. Haces el commit del fichero con el comando `git commit -m <comentario commit>`
4. Entras a GitHub y creas el repositorio
